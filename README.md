# Prettier Tags

## Description
Prettier Tags is an open-source script for the [Overlayer](https://github.com/modlist-org/Overlayer) mod made for the game A Dance of Fire and Ice.
It is based on iTags, Better iTags Alpha, Not Enough Tags, maimai.js, and made with the help from BadWolf and owosean.

## Compatibility
### Version I
**ARCHIVED**
Tested on ADOFAI version 2.9.8 with Overlayer mod 3.49.0.
Certain tags such as GPU usage metrics will only work on Windows systems due to how the Overlayer mod is coded.
Certain tags require other mods to work. For example, the XPerfect tags need [XPerfect](https://github.com/8100print/XPerfect) 1.3.0 or above to work.
### Version II
**CURRENTLY IN ALPHA**
Tested on ADOFAI version 3.4.0 (Alpha) with Overlayer mod 5.9.1 and Overlayer.Module.ADOFAI 1.4.2.
Some tags are currently missing compared to Version I, this is either intentional since some tags are outdated and meaningless in the context of modern ADOFAI, such as the (Non-X) Accuracy related tags; or because it is simply not possible with the current native Overlayer tags, such as the CPUUsage tags.

## Installation
### Version I
Download the Prettier.Tags.js file from [releases](https://github.com/nuomibinggao/Prettier-Tags/releases), place it in your ADOFAI game path/Mods/Overlayer/Scripts/Prettier.Tags.js, and restart your game.
### Version II
Download the Prettier.Tags.js file from [releases](https://github.com/nuomibinggao/Prettier-Tags/releases), place it in your ADOFAI game path/UserData/Overlayer/JS/Script/Prettier.Tags.js, and restart your game.
You may need to refresh the script in the JS menu of the Overlayer mod for it to register.
